# Mechanical Transformer

Code for the numerical experiments in the paper.

- `01_elastostatic_transformer`: elastostatic lattice Transformer training and Figure 1.

- `02_regression_operators`: regression operator training, Figure 2, Figures S2–S3, and Table S1.

- `03_physical_realization`: lattice fitting and inference, Figure 3, Figure S4, and Tables S2–S3.

- `04_compliance_fitting`: compliance fitting, dimension and connectivity studies, and Tables S4–S6.

- `05_mall`: MALL training, Figures 4–5 and S5, Tables S7–S9, and fabrication tolerance (Table S11).

- `06_rigidity_constraints`: bounded-rigidity and three-class studies, Figures S6–S7, and Tables S10 and S12.

- `07_language_model`: mechanical language-model training, Figure 6, Figure S8, and Tables S13–S14.

See each experiment folder for its environment and run commands.
